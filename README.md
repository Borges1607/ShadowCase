# 🕵️ ShadowCase

> **Desvende os mistérios. Encontre as pistas. Resolva o caso.**

**ShadowCase** é uma plataforma de jogos de investigação e enigmas, desenvolvida para proporcionar uma experiência imersiva de investigação criminal diretamente pelo navegador.

O jogador assume o papel de um detetive e precisa analisar pistas, conectar informações, interrogar suspeitos e solucionar diferentes casos utilizando raciocínio lógico e capacidade de investigação.

## 🎮 Sobre o projeto

O ShadowCase tem como proposta transformar a resolução de enigmas em uma experiência interativa.

Cada caso apresenta uma história, personagens, evidências e pistas que devem ser analisadas pelo jogador. O objetivo é descobrir o que realmente aconteceu e chegar à conclusão correta.

O projeto atualmente possui um **protótipo interativo desenvolvido no Figma Make**, utilizado para validar a interface, os fluxos de navegação e a experiência do jogador antes da implementação definitiva. O Figma Make permite criar e testar protótipos funcionais e iterar sobre suas interações.

## 🔎 Como funciona

O jogador deverá:

1. 🗂️ Escolher um caso para investigar;
2. 📖 Conhecer a história e o contexto do caso;
3. 🔍 Investigar pistas e evidências;
4. 👤 Analisar os suspeitos;
5. 🧩 Resolver enigmas e conectar informações;
6. 🧠 Formular uma teoria sobre o acontecimento;
7. ⚖️ Apresentar sua conclusão;
8. 🏆 Receber o resultado de sua investigação.

## 🎯 Objetivo

O principal objetivo do ShadowCase é criar uma experiência de investigação acessível e envolvente, combinando **narrativa, lógica e interatividade** em uma plataforma web.

A proposta é fazer com que cada caso seja uma experiência de investigação na qual o jogador precise realmente analisar as informações disponíveis para chegar à solução.
